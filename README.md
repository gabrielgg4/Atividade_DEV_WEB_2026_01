# Atividade_DEV_WEB_2026_01

## Descrição
Repositório da atividade de Desenvolvimento Web referente ao período 2026/01.

## Estrutura do Projeto

### `README_parte1.md`
Contém todos os requisitos e informações solicitadas na Parte 1 da atividade.

### `/frontend`
Diretório destinado ao código do frontend da aplicação.  
Só tem o basico de um projeto.

### `ChatCopilot_parte1.md`
Registro da conversa utilizada como apoio no desenvolvimento da atividade.

Inicialmente foi utilizado o Claude, porém devido às limitações de uso, o restante do suporte foi feito com o GitHub Copilot/Chat.  
Como não há opção de compartilhamento direto da conversa, o conteúdo foi exportado manualmente para este arquivo.
